# @costfluent/sdk

TypeScript client for the [Costfluent](https://costfluent.com) Public API: every operation typed
from the API's OpenAPI document, with retries, idempotency keys, pagination and errors handled for
you. It runs wherever `fetch` does: Node.js 20 or later, Deno, Bun and edge runtimes.

```bash
npm install @costfluent/sdk
```

You need an API token, created under **Settings**, **API tokens**, on a plan that includes API
access. Give the token only the capabilities your script needs, and keep it on a server: a token
in a browser bundle is a token anyone can read.

## Quick start

```ts
import { createClient } from "@costfluent/sdk";

const client = createClient({ token: process.env.COSTFLUENT_API_TOKEN! });

const { data } = await client.GET("/v1/workspaces/{workspaceId}", {
  params: { path: { workspaceId: "wsp_..." } },
});
console.log(data?.name);

await client.POST("/v1/folders", { body: { workspaceId: "wsp_...", title: "Finance" } });
```

Operations are addressed by method and path, with the path, query and body typed from the API, as
[openapi-fetch](https://openapi-ts.dev/openapi-fetch/) does. `createClient` takes `token`,
`baseUrl`, `timeoutMs` (each attempt, 30 seconds unless set), `maxRetries` and `fetch`. The
schema types are exported as `paths`, `components` and `operations`, so
`components["schemas"]["WorkspaceResponse"]` names a model.

## Pagination

A list answers one page with `links` and `data`. `paginate` yields every item, following
`links.next` until it is empty; you make the typed call and pass on the `querySerializer` it
hands you:

```ts
import { paginate } from "@costfluent/sdk";

for await (const workspace of paginate((querySerializer) =>
  client.GET("/v1/workspaces", { params: { query: { limit: 100 } }, querySerializer }),
)) {
  console.log(workspace.id, workspace.name);
}
```

The next page is always requested from the client's own base URL, so the token goes nowhere else.

## Money

Amounts are strings holding the exact decimal the API computed, such as `"1234.56789012"`, never
JavaScript numbers. Keep them as strings, or use a decimal library to calculate with them.

## Errors and retries

Any error status throws `CostfluentError` once retries are spent, so a call that returns has its
`data`. The error carries `status`, the API's `code` (`not_found`, `validation_failed`,
`idempotency_key_reused` and so on), the full `problem` details, `fieldErrors` and the
`requestId` to quote to support, with `isNotFound`, `isRateLimited` and `isIdempotencyKeyReused`
for the common checks.

- A 429 is retried for every method, after the `Retry-After` or `RateLimit-Reset` the API sends.
- A 5xx, a connection error, or a 404 that is not the API's own problem details (a proxy's) is
  retried for GET, HEAD, PUT, DELETE and creates, but not for other POSTs, which trigger work, nor
  for a request with `If-Match`.
- Retries back off exponentially from one second with jitter, at most three times. A wait over 60
  seconds is not waited out: the error is thrown at once. An attempt that times out is not retried.

Every create sends a fresh `Idempotency-Key` and resends it on each retry, so a retried create is
answered with the first response instead of creating twice. Set
`params: { header: { "Idempotency-Key": "..." } }` to choose the key yourself, for example to make a
scheduled job's create safe to run again.

## Versions

Releases are `1.MINOR.PATCH`, numbered with the Costfluent Go and Python clients. The major is the
API's path version, `v1`, which only grows; the minor rises with each release that carries a newer
API contract, the patch is a fix to the client alone. `CONTRACT_SHA256` is the SHA-256 of the API
document a release was generated from, and `VERSION` the package's own version.

## Development

`src/schema.ts` is generated by `openapi-typescript` and `src/contract.ts` beside it; the rest is
written by hand.

```bash
npm ci
npm run build
npm run typecheck
npm test
```
